# Nurse Career Change Freebies Kit

Printable worksheets for nurses moving into a new career — bedside to your next role. Large-print friendly, no account needed, education only.

**Publisher:** Asdale Dynamics, LLC (Indiana, formed October 2026)
**Founder:** Dylan Asdale, RN, AI author
**License:** MIT
**Cost:** Free, no account needed

## What's inside

This kit has four printable worksheets:

1. **Skills Inventory** — Check the nursing skills you already have, rate your confidence (1 = rusty, 5 = expert), and map each one to transferable skills for work outside healthcare.
2. **Resume Translation** — Convert nursing-speak into plain English resume language employers outside healthcare recognize, with example bullets you can adapt.
3. **Job Application Tracker** — One row per application, with a status legend, weekly goal, and contacts-to-nurture section.
4. **Interview Prep Worksheet** — STAR-method answer spaces for the most common interview questions, plus a post-interview thank-you template.

## How to use it

### Print from the HTML
Open `index.html` in your browser and print (Ctrl+P / Cmd+P). Choose "Save as PDF" or your printer. For a clean worksheet, disable headers/footers in the print dialog. The kit is large-print friendly and designed to print well.

### Read the Markdown source
The Markdown versions live in `markdown/`:
- `kit.md` — all four sections combined
- `01-skills-inventory.md`
- `02-resume-translation.md`
- `03-job-application-tracker.md`
- `04-interview-prep.md`
